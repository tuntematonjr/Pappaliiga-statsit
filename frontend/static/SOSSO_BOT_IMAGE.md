# Sössö Bot Image

## Default Path
- `frontend/static/sosso-bot-logo.png`
- Served as `/static/sosso-bot-logo.png`

## Replace Image
1. Put the new file at the same path, or
2. Update the `logo` field in `frontend/static/views/HomeView.js` (`sosso-bot` callout).

Recommended format: square PNG (transparent background preferred).

## Links
Sössö callout URLs are defined in `frontend/static/views/HomeView.js` (`primaryHref`, optional `secondaryHref`).
